# 중식 연습장

기존 양식조리기능사 앱의 두 메뉴 동시 연습 흐름을 바탕으로 새로 만든 중식 실기 공부 페이지입니다. 기존 양식 파일과 학습 데이터는 변경하지 않았습니다.

## 사용하기

`index.html`을 브라우저에서 여세요. `styles.css`, `data.js`, `app.js`, `fonts/` 폴더를 함께 두어야 합니다. 별도 설치나 외부 라이브러리, 온라인 글꼴 연결이 필요하지 않습니다. 제목·본문·버튼·입력창에는 동봉한 Pretendard 가변 글꼴을 사용합니다.

현재 Codex 미리보기 주소: http://127.0.0.1:4178/

1. 두 메뉴를 선택하거나 무작위 조합을 고릅니다.
2. 규격을 확인하고 재료를 A 메뉴·공통·B 메뉴로 분류합니다.
3. 기억한 순서를 적고 학습 예시와 비교합니다.
4. 위·아래 버튼으로 조리 카드를 정리합니다.
5. 결과와 다시 볼 부분을 학습 노트에서 확인합니다.

메뉴 도감에는 20개 메뉴의 주요 규격, 지급재료, 예시 순서와 메모가 있습니다. 메뉴·재료 검색, 학습 완료 표시, 개인 시험일, 일시정지, 진행 중 연습 복원을 지원합니다.

## 저장 방식

기록은 현재 기기·브라우저·접속 주소의 로컬 저장소에 저장됩니다. 양식 앱과 다른 저장 키(`jungsik-study:v1`)를 사용합니다. 최초 기록은 모두 0이며 예제 기록은 들어 있지 않습니다. 다른 기기로 자동 동기화되지 않습니다. 브라우저 데이터 삭제 또는 접속 주소 변경 시 기록이 보이지 않을 수 있습니다.

진행 중 연습은 새로고침 후 홈의 ‘이어서 연습’으로 복원합니다. 실행 중이던 타이머는 지난 시간을 반영한 뒤 복원 대기 상태에서 멈춥니다. 메뉴 메모는 입력 즉시 저장합니다. 손상된 저장 형식은 검증 후 기본 상태로 열며 기존 양식 데이터를 읽거나 삭제하지 않습니다.

실습 메모 18개와 참고 글 2개를 반영한 20개 메뉴의 이전 5단계 연습을 불러오면 해당 메뉴의 새 순서 카드를 준비하고 재료 단계부터 이어갑니다. 홍쇼두부·새우볶음밥은 각각 10단계, 양장피잡채는 18단계, 해파리냉채·오징어냉채·빠스옥수수는 각각 8단계, 라조기·깐풍기·울면·새우케첩볶음은 각각 13단계, 경장육사·고추잡채·채소볶음은 각각 11단계, 탕수육은 16단계, 마파두부는 15단계, 부추잡채는 7단계, 빠스고구마는 6단계, 난자완스는 9단계, 유니짜장면·탕수생선살은 각각 12단계입니다. 작성한 서술, 남은 시간, 완료 기록과 개인 메모는 보존합니다.

## 파일 구성

- `index.html`: 공통 화면과 접근성 구조
- `styles.css`: 데스크톱·모바일 공통 디자인
- `data.js`: 중식 20개 메뉴의 학습 자료
- `app.js`: 연습, 타이머, 검색, 메모, 결과·복원 기능
- `fonts/PretendardVariable.woff2`: [Pretendard](https://github.com/orioncactus/pretendard) v1.3.9 가변 글꼴
- `fonts/OFL.txt`: 글꼴의 SIL Open Font License 원문

## 검증 결과

- 메뉴 20개: 공식 과제 시간과 재료 개수 대조 완료.
- 가능한 두 메뉴 조합 190개: 재료 중복 및 합집합 점검 완료.
- 실제 브라우저: 중복 메뉴 차단, 미분류 안내, 정답·오답 표시, 순서 카드 이동, 결과 저장 확인.
- 새로고침: 진행 중 단계·서술 내용·타이머·메모 복원 확인.
- 메모의 HTML 표기: 실행되지 않고 일반 텍스트로 표시됨을 확인.
- 390px·320px 화면: 가로 넘침 없이 표시. 콘솔 오류 없음.
- 기존 양식 최신본 SHA256 동일 확인. 기존 완료본·업로드 폴더·이미지 자산 수정 없음.

현재 구현은 독립된 정적 페이지입니다. 계속 수정할 때는 이 폴더의 4개 앱 파일을 대상으로 하고, 기존 양식 앱은 참고용으로만 사용하세요.
